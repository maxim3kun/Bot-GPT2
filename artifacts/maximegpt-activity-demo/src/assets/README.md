# Walk cycle

`quaternius-walk-loop.json` contains the retargeted `Walk_Loop` animation from
Quaternius' Universal Animation Library Standard.

- Source pack: https://quaternius.com/packs/universalanimationlibrary.html
- Source mirror and license: https://github.com/IAFahim/quaternius.universalAnimationLibrary.standard
- License: CC0 1.0 Universal

The original FBX was reduced to the humanoid rotation tracks used by the
Maxime VRM. The avatar model itself is unchanged.

# Humanoid animation source pack

`animations/cc0-humanoid-motions.glb` is used only as a source for its `idle`
and `walk` animation tracks. Its character mesh is never added to the visible
scene; Maxime's uploaded VRM remains the character shown in the room.

- Source: https://github.com/Vuena/free-low-poly-characters-cc0
- Original sample: `GLB/blocky_01_hero.glb`
- License: CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/
- The source pack also includes run, jump, wave, cheer, and dance clips for
  later use.
