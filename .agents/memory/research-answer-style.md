---
name: Research answer style
description: User-facing formatting expectations for researched MaximeGPT answers.
---

For web-researched answers, answer directly and briefly. Prefer plain prose or a few bullets; do not use Markdown tables or pipe-separated formatting unless the user explicitly requests a table. Latest-news replies should focus on at most three distinct items, and sources should be available without repeating a directory of sites in the answer.

**Why:** The user said the bot's researched answers were too long and that Markdown tables looked ugly.

**How to apply:** Use these defaults in researched-response prompts and formatting, while still giving more detail when the user explicitly asks for it.
