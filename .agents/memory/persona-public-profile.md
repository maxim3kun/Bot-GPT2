---
name: Persona public profiles
description: Privacy and server-scope rules for creator-authored public persona profiles.
---

Only publish text explicitly written by a persona creator. Scope each profile to one Discord server and show it only alongside that creator's public personas in that same server. Do not infer or publish creator identity, avatar details, generated role profiles, memories, or other private data.

**Why:** The user requires public discovery without automatically exposing personal data, private personas, memories, or details they did not choose to share.

**How to apply:** Keep profile storage and every public lookup scoped by both creator and guild; public views should contain only creator-selected fields.
