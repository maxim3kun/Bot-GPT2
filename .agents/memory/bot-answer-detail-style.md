For conversational AI replies, give the direct answer first and keep ordinary responses concise without imposing a fixed word limit. When useful context was left out, let the user request it on demand. Preserve sources, verified calculations, necessary caveats, language, and persona voice in expanded replies.

**Why:** The user said bot answers can be unnecessarily long and agreed that details should be available through a button or command rather than included by default.

**How to apply:** Keep structured transport schedules and other domain-specific cards governed by their own presentation; apply this default to generated chat replies and make expansion optional and private to the requester.
